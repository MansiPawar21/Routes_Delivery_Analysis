# 📌 Project Overview

**Deliveries & Routes Analysis** is a data analytics project developed to analyze delivery performance, delivery delays, routes, hubs, service types, and monthly delivery trends.

The project demonstrates an end-to-end data analysis workflow using multiple tools:

- **MySQL** for database creation and SQL-based data management
- **Microsoft Excel** for data preparation, calculations, summaries, and dashboard analysis
- **Python** for data processing and analytical operations
- **Pandas** for data cleaning, transformation, and merging
- **Matplotlib** for data visualization
- **Jupyter Notebook** for performing Python-based analysis

The main purpose of this project is to understand how delivery performance changes based on the promised delivery time, actual delivery time, route, service type, hub, and month.

The project starts with structured delivery data stored in a MySQL database and continues through Excel and Python analysis before presenting the results through a visual dashboard.

---

# 🎯 Project Objectives

The main objectives of this project are:

1. To analyze delivery performance using structured delivery data.
2. To compare promised delivery days with actual delivery days.
3. To identify and calculate delivery delays.
4. To analyze delivery delays by service type.
5. To analyze delivery trends across different months.
6. To understand delivery performance across different hubs.
7. To analyze different delivery routes.
8. To combine delivery information with route information.
9. To perform data cleaning and transformation using Python.
10. To create meaningful summary metrics and KPIs.
11. To visualize delivery-related information through charts.
12. To present the final analysis through a dashboard.
13. To demonstrate practical knowledge of SQL, Excel, Python, and data visualization.

# 🗂️ Dataset Overview

The project dataset contains delivery information for multiple routes and hubs across three months.

The dataset includes:

- **12 delivery records**
- **4 routes**
- **3 months**
- **3 hubs**
- **2 service types**

### 📅 Months Covered

The delivery data covers:

- January
- February
- March

### 🏢 Hubs Covered

The dataset contains the following hubs:

- Mumbai

### 📦 Service Types

The project contains two service types:
